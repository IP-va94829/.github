<p>本文按动手顺序讲清在路由器上接入海外住宅 IP 的流程：先判断设备能力，再接线、拨号、配代理转发、做内网分流，最后验证排错。每一步都说明判断依据，卡住时可直接对照文中的现象表定位。</p>
<h2>一、先看路由器能不能承担</h2>
<p>后台菜单里能找到代理客户端、VPN 客户端或策略路由的机型，才适合把整条线路的出口换掉。</p>
<p>只有拨号功能的家用路由器，一般要把代理放到电脑或旁路由上，硬刷固件存在把设备刷坏的风险。</p>
<p>买之前先登录后台翻一遍菜单，确认有没有相关选项，比看宣传页和客服话术可靠。</p>
<h2>二、物理接线决定谁来拨号</h2>
<p>服务商通常给三条信息：接入地址、账号、密码，形态可能是 PPPoE，也可能是固定网关加静态地址。</p>
<p>PPPoE 要让路由器自己拨号，光猫改成桥接；静态方式保留光猫拨号，路由器 WAN 口填固定地址。</p>
<p>这一层接错，后面怎么配都不通，所以先确认 WAN 灯状态和拨号结果，再往下走。</p>
<h2>三、后台里只填必须的几项</h2>
<p>PPPoE 页面填账号和密码，服务名一般留空，填错会表现为反复重拨、日志里全是超时。</p>
<p>静态方式要填 IP、掩码、网关和 DNS，掩码常见 255.255.255.0，网关用服务商给的那一个。</p>
<p>保存后看 WAN 口有没有拿到地址，没有就先解决拨号问题，别急着改代理配置。</p>

<h2>四、把代理接进转发链路</h2>
<p>代理参数只有四项：地址、端口、用户名、密码，端口一定要以服务商给的那份为准。</p>
<p>路由器支持透明转发时，把内网网段直接指向代理，终端不用改任何设置就能生效。</p>
<p>不支持时用旁路由网关或端口映射，规则里要写清源网段，别把管理后台也一并代理出去。</p>
<h3>透明转发和端口映射怎么选</h3>
<p>透明转发对终端无感，适合设备多、人员杂的环境，但排错时不容易定位是哪一层出的问题。</p>
<p>端口映射要逐台填代理地址，配置繁琐，好处是每个端口对应一台设备，出问题一眼就能看出来。</p>
<h2>五、内网设备按需分流</h2>
<p>不是所有设备都该走同一条出口，策略路由可以按 MAC 地址或 IP 段把流量分组。</p>
<p>办公机走本地宽带，业务设备走住宅线路，两边互不影响，也不会互相抢带宽。</p>
<p>DNS 建议跟着代理走，能减少解析地区与出口地区不一致导致的登录异常。</p>

<h2>六、验证与故障对照</h2>
<p>验证就两步：查出口 IP 的归属城市和运营商，再连续 ping 十分钟看延迟抖动。</p>
<p>出口没变多半是分流规则没命中，时通时断多半是线路质量或保活没开。</p>
<p>日志里能看到拨号记录和转发命中情况，出问题先看日志，再决定改哪一层。</p>
<h3>多久复检一次比较合适</h3>
<p>新配置上线后一周内每天看一次出口和延迟，稳定之后再拉长到每月一次。</p>
<p>服务商调整线路不会提前通知，出口城市突然变化时，要按新地址重新核对账号环境。</p>
<h2>常见问答</h2>
<h3>路由器不支持代理功能，还有别的办法吗？</h3>
<p>答：可以在内网加一台旁路由或小主机做网关，把需要换出口的设备网关指向它，原路由器只负责拨号和交换。</p>
<h3>配好之后只有部分设备生效，是什么原因？</h3>
<p>答：多数是分流规则只覆盖了某个网段或某些 MAC，检查策略路由的匹配条件和顺序，规则从上往下命中。</p>
<h3>住宅线路会不会影响家里原来的宽带使用？</h3>
<p>答：两条线路互不影响，只要分流写清源地址，业务设备和家用设备各走各的出口，带宽也不会互相挤占。</p>
<h3>MTU 一般设多少比较稳？</h3>
<p>答：跨境链路常见 1400 到 1450，出现大包丢失、网页半开时先降 MTU 再测，不要一上来就设成 1500。</p>
